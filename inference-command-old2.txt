FROM FOLDER OF PNG FILES - TAKING FROM METADATA - COMPARISON PAIR (prompt-only vs all-settings):
  prompt_only_and_all_settings mode renders TWO images per prompt at the SAME --seed (metadata seed is
  ignored) so only the settings differ: one *_promptonly image (all settings from the CLI defaults) and
  one *_allsettings image (Steps/CFG/Seed/Size/Sampler/Scheduler from the metadata). --images_per_prompt
  N makes N such pairs, pair k at seed+k. --prompt_count_skip_first paginates (run 2, then next 2):
  uv run sd-scripts/anima_minimal_inference.py \
      --dit  /media/aikenyon/WDRed16TB/models/anima/split_files/diffusion_models/anima-base-v1.0.safetensors \
      --vae  /media/aikenyon/WDRed16TB/models/anima/split_files/vae/qwen_image_vae.safetensors \
      --text_encoder /media/aikenyon/WDRed16TB/models/anima/split_files/text_encoders/qwen_3_06b_base.safetensors \
      --lora_list \
          /media/aikenyon/WDRed16TB/models/loras/div2k_anima/div2k_anima_v1-step00000360.safetensors \
          1.0 \
      --from_image_embed prompt_only_and_all_settings /media/aikenyon/WDRed16TB/sd/source_content/prompt_source \
      --image_size 1216 832 --infer_steps 50 --guidance_scale 3.5 --flow_shift 2.0 --seed 42 \
      --prompt_count 2 --prompt_count_skip_first 0 \
      --images_per_prompt 1 \
      --save_path ./anima_out --output_type images \
      --sampler er_sde --scheduler beta57

  Notes:
  - --from_image_embed takes the folder; prefix it with the literal keywords prompts_only,
    ignore_negative_prompt, and/or prompt_only_and_all_settings (any order) to switch modes.
  - ignore_negative_prompt discards the metadata negative so it falls back to --pre_prompt_neg / blank.
  - Global defaults (--image_size H W, --infer_steps, --guidance_scale, --flow_shift, --seed, --sampler,
    --scheduler) are the prompt-only values AND the per-image fallbacks in full-settings mode.
    --image_size is HEIGHT WIDTH. er_sde/beta57 are now the built-in defaults, so --sampler/--scheduler
    are optional unless overriding.
  - Sampler/Scheduler are pulled from metadata only when they map to a script choice (euler/er_sde,
    default/beta57); A1111 values like "Euler a" or "Karras" don't map and fall back.
  - --seed accepts -1 (or omit it) for a random seed.
  - --images_per_prompt 4 -> 4 seed-incremented variations per prompt (seed, seed+1, ...).
  - --prompt_count 10 caps to the first 10 USABLE prompts (PNGs with no positive prompt are skipped and
    do not count). --prompt_count_skip_first 4 skips the first 4 usable prompts first, for pagination.
    Both apply to --from_folder / --from_file / --from_image_embed.
  - In full-settings mode a metadata value overrides the matching global default per-image; settings
    mode needs BOTH Steps and CFG in the metadata, otherwise that image reverts to prompts-only.
